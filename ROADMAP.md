# MileSage roadmap

## Tutorial for future builds

Requested November 25, 2026 after the Android interface test was approved on the phone.

Add a version-matched first-run tutorial and an always-available Help or Replay tutorial entry on both Android and desktop. Let returning users skip it. Use disposable demonstration data and preserve their real garage.

The walkthrough should cover:

- Finding Home on the phone and Dashboard on desktop, selecting the correct vehicle, adding a photo, and using the + Add, Subtract and Set exact odometer controls.
- Manual entry and VIN lookup with review before saving.
- Fuel entry, total paid versus price per gallon, octane versus ethanol blend, partial fills and full-tank MPG.
- Service entries, intentional reminder resets, tire pressure, fluids and filters.
- Receipt scanning and OCR review, multi-page PDFs, explicit Save actions, and reattaching PDFs.
- Graphs, manual resale snapshots, separate Car History and annual review reminders.
- Full mobile backups versus desktop exports, PDF files saved separately, and the absence of automatic PC/phone synchronization.
- Optional feedback sharing and basic recovery/troubleshooting.

Include annotated screenshots or short captioned demonstrations, readable text, accessible controls, and a clear completion/skip path. Keep the tutorial's labels aligned with each released build and test it with a new user. Link the written guide as a companion reference.

Status: planned for future builds. This documentation update does not implement an in-app tutorial or change the distributed APK.
