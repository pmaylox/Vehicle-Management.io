Data & backup

Bring in your existing records

This version checks your public GitHub vehicle records when opened and approximately every 2 minutes while visible. It automatically updates only when your local copy has no unmerged changes. Manual import below replaces local records after confirmation. Phone edits never upload to GitHub.

Your GitHub backup may be older than the laptop copy. Import the newest file available, and export a backup before replacing existing phone records.

Save a backup

Phone edits are saved in this browser, not uploaded to GitHub or your laptop. Export regularly before clearing browser data or changing phones.

The Python export uses the same vehicle JSON structure as your desktop app. Mobile-only expense and mileage-log details are included in the full backup.
